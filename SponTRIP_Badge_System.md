# SponTRIP Badge System

## Badge Philosophy

SponTRIP uses a playful **"Drawing → Tuloy"** theme inspired by the Filipino expression *"drawing lang"* for plans or events that never happen.

The badge system rewards users who:
- Create and complete experiences.
- Participate consistently.
- Build Circles and communities.
- Explore different places and activities.
- Actually show up.

It also uses humorous **Drawing badges** for repeated no-shows.

# 4. Tuloy Score

Badges should complement, not replace, the user's attendance reputation.

Every Sponie can have a visible **Tuloy Score**.

### Example: Reliable Sponie

```text
Yu

🔥 96% Tuloy

48 / 50 events attended

🌅 Amorsolo
Hindi drawing. Natutuloy.
```

### Example: Professional Drawer

```text
Sponie

🔥 42% Tuloy

21 / 50 events attended

🎨 Da Vinci of Drawing
Plans beautifully. Shows up artistically.
```

## Tuloy Score Formula

```text
Tuloy Score =
Events Attended / Confirmed Events × 100
```

Cancelled events should not count as no-shows when the cancellation is made within the allowed cancellation policy.

# 6. Core SponTRIP Brand Concept

The badge system should reinforce the central SponTRIP idea:

> **Every trip starts as a drawing.**
>
> **Every Circle creates the canvas.**
>
> **Every memory becomes a masterpiece.**

The ultimate progression is:

```text
✏️ DRAWING
    ↓
🎨 SKETCH
    ↓
🚀 TULOY
    ↓
📸 MEMORY
    ↓
🖼️ MASTERPIECE
```

SponTRIP's goal is simple:

> **Don't just draw plans. Make them Tuloy.**
